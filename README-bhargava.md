# GEN_AI_MASTERY_PRACTICE_FILES

A multi-step AI prompt workflow for automated interview preparation and
personalized mock interviews.

## Overview

**GEN_AI_MASTERY_PRACTICE_FILES** is a prompt-engineering workflow
designed to make interview preparation more structured, personalized,
and reliable.

The workflow analyzes a candidate profile, creates an interview
preparation plan, generates technical and behavioral questions with
answers, and applies AI-based critique and refinement before producing
the final preparation material.

## Workflow

The project follows a three-stage pipeline:

``` text
Candidate Profile
       ↓
Stage 1: Planning
       ↓
Interview Plan
       ↓
Stage 2: Question Generation
       ↓
Mock Interview Preparation
       ↓
Stage 3: Critique & Refinement
       ↓
Final Interview Preparation
```

## Key Features

-   Candidate profile analysis

-   Behavioral question generation

## Three-Step Prompt Workflow

### 1. Candidate Profile & Interview Planning

The first stage analyzes the candidate's profile and target role.

It identifies:

-   Candidate level
-   Target role requirements
-   Technical skills
-   Behavioral areas
-   Preparation objectives
-   Recommended question sequence
-   Practice activities

The output is a structured interview preparation plan.

### 2. Mock Interview Question Generation

The second stage uses the approved interview plan to generate:

-   Technical questions
-   Behavioral questions
-   Model answers
-   Short explanations
-   Examples
-   Practice prompts

The generation remains aligned with the approved plan to avoid
unnecessary topics.

### 3. Critique, Validation & Refinement

The final stage acts as a quality-control step.

It checks:

-   Whether all preparation objectives are covered
-   Relevance to the target role
-   Suitability for the candidate level
-   Logical question sequence
-   Repeated or unrelated questions
-   Accuracy and clarity of answers
-   Required length and formatting

Problems identified during the review are corrected before the final
preparation material is produced.

## Project Objective

The main objective is to demonstrate how a complex AI task can be
divided into smaller prompt-driven stages.

Instead of using one large prompt, the workflow uses:

**Planning → Generation → Review**

This provides checkpoints between stages and improves the
controllability and consistency of the generated interview preparation
material.

## Expected Output

The final output is a structured and personalized interview preparation
resource containing relevant questions, answers, explanations, and
practice material suitable for the candidate and target role.
